# 📥 Media Downloader

YouTube ve diğer popüler platformlardan yüksek kalitede video ve ses indirmenizi sağlayan, minimalist ve modern bir masaüstü uygulamasıdır. Python ve CustomTkinter kullanılarak geliştirilmiştir.

## 🚀 Özellikler
* **Yüksek Kalite Video İndirme:** 1080p, 720p ve 480p çözünürlük destekleri.
* **Sadece Ses (MP3):** Videoları doğrudan MP3 formatında indirebilme.
* **Otomatik Klasörleme:** İndirilen dosyalar otomatik olarak bilgisayarınızın `İndirilenler` klasörüne kaydedilir.
* **Modern Arayüz:** Göz yormayan, yüksek kontrastlı karanlık tema (Dark Mode).
* **Kullanıma Hazır:** Kurulum gerektirmez, taşınabilir (Portable) `.exe` formatındadır.

## 💻 Nasıl Kullanılır?
1. Sağ taraftaki **Releases** bölümünden en güncel `.zip` dosyasını indirin.
2. Klasörü masaüstüne çıkartın.
3. `MediaDownloader.exe` dosyasına çift tıklayarak uygulamayı başlatın.
*(Not: `ffmpeg.exe` dosyasının uygulamanın yanında olduğundan emin olun).*

## 🛠️ Geliştiriciler İçin (Açık Kaynak)
Bu projeyi kendi bilgisayarınızda derlemek isterseniz:
1. `app.py` dosyasını indirin.
2. Gerekli kütüphaneleri kurun: `pip install yt-dlp customtkinter pillow requests`
3. Projeyi çalıştırın: `python app.py`
